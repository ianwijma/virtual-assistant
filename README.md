# Virtual Assistant

> Working title. The product name is chosen together with the visual identity.

One self-hosted assistant for a whole household. A server on the local
network is the hub, and every device the household already owns is a client
of it: desktops, phones, tablets and browsers. It has a voice, a fast desktop
hub, and it keeps your data in your home.

**Status: planning.** There is no code yet. This repository currently holds
the design, which includes the decisions made so far.
