# Typography

The typefaces and the type scale. Part of [the visual design](README.md).

Status: started. The typeface is not chosen yet.

## Design

- **One typeface is shipped with every client,** so that text looks the
  same on every device. No client uses the font of the platform it runs
  on. Apple's San Francisco cannot be used outside Apple's devices.
- **Its licence must allow sold hardware,** like every other dependency.
  See [licensing and hardware](../technical/licensing-and-hardware.md).
- **Text follows the text size set on the device.** A person who has set
  larger text on their phone gets larger text in the app.
- **Numbers that change in place,** such as a running timer, have digits
  of equal width, so that they do not jump.
