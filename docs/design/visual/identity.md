# Identity

The name, the feel, and what makes the product recognisable. Part of
[the visual design](README.md).

Status: started. The feel is set. The name is open.

## Design

- **The product is recognisable as ours,** on every device.
- **It feels calm, warm, precise and playful.** The interface is the calm
  and precise part: quiet, clean and fast, so that it suits a power user
  at a desktop. The assistants are the warm and playful part: the
  characters, their expressions and their voices bring the life, so that
  it suits a home. It is both a tool and a thing for the home.
- **Who a screen is designed for depends on the device.** The desktop is
  for a power user first. A phone serves power users and the rest of the
  household. A display in a room is for the whole household. Each device
  has a strong default, and its density can be changed. See
  [shape and spacing](shape-and-spacing.md).
- **The look is inspired by Apple's Liquid Glass, and is not a copy of
  it.** See [glass](glass.md). What sets it apart is a question below.
- **The logo mark is the glass drop:** a speech bubble that is also a
  head, with two eyes, drawn as clear glass with a bright edge and a glow
  inside. This is "D2. Glass drop" on
  [the second logo board](examples/logo-board-2.html). It is a candidate
  like the name, to be drawn properly once the name is settled.
- **The name and the logo are chosen together with this work.** "Virtual
  Assistant" is a working title. The name is to mean or suggest home,
  homeliness or family, and a Dutch word is welcome.
- **"Hearth" is not the name.** It was chosen from
  [the name and logo board](examples/name-and-logo-board.html) and then
  dropped: Hearth Display sells a family display for the wall under that
  name and is reported to hold a United States trade mark for it on
  touchscreen devices and household software.

## What could make it ours

These are the candidates, shown on
[the direction board](examples/direction-board.html). They can be
combined.

| Candidate | What it means |
|---|---|
| The colour | An accent and a tint that Apple does not use |
| The backdrop | Our own soft, moving colour behind the glass, the same on every device |
| The assistants | The characters are the face of the product, and the interface around them stays quiet |
| An assistant's colour | The backdrop takes the colour of the assistant that is active, so the screen shows who is listening |
| The shape | A corner and a control shape that are our own |

## Verified and assumed

Checked on 28 November 2026 for eighteen names that mean home, by a web
search for products, the Rust package index, GitHub and the name records
of four web addresses each:

- No product in home or assistant software was found under "Heem",
  "Heemo", "Huize" or "Stekje". An unrelated Dutch app is called "Stek".
  A Rust package "knus" exists, and KNUSS is a Belgian maker of heated
  furniture.
- "Haard", "Thuis", "Honk", "Erf", "Samen", "Nest", "Domi", "Oikos",
  "Lar" and "Kin" were set aside: each is in use in this field, crowded,
  hard to say in English, or sounds wrong in English or German.
- No trade mark register could be reached, so no name is checked there.
- A missing name record does not prove that a web address is free.
- How an English speaker says each name is assumed, not tested.
